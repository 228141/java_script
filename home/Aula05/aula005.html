Tipos Primitivos

Tipo Primitivo Descrição Exemplo String / Sequência de caracteres para representar textos. / let nome = "Maria"; Number / Representa números (inteiros e decimais). / let idade = 25; Boolean / Valor lógico: true (verdadeiro) ou false (falso). / let ativo = true; Undefined / Dado que foi declarado, mas ainda não recebeu nenhum valor. / let resposta; Null / Ausência intencional de qualquer valor. / let dado = null; Symbol / Identificador único e imutável, usado muito para chaves de objetos. / let id = Symbol("id"); BigIntNúmeros / inteiros grandes que ultrapassam o limite seguro do Number. / let grande = 123n; Object / a linguagem JS tem este como um tipo primitivo function / Também é considerado um tipo primitivo em JS

Existe outros valores internos dentro dos tipos primitivos, por exemplo: O NUMBER tem dois valores internos importantes, o "Infity" e o "NaN" (not and number) O que é Infinity? Representa o infinito matemático. Ocorre quando uma operação matemática excede o limite máximo que o JavaScript consegue representar, ou quando ocorre uma divisão por zero. Exemplo: 1 / 0 resulta em Infinity. Existe também o -Infinity (infinito negativo), retornado ao dividir um número negativo por zero. Útil para comparações onde você precisa de um valor maior (ou menor) do que qualquer outro número existente. O que é NaN? É a sigla para Not a Number (Não é um Número). Ele é gerado quando ocorre um erro computacional ou quando uma operação matemática resulta em um valor indefinido. Exemplo: Tentar multiplicar uma String por um número (ex: "texto" * 2) resulta em NaN. O NaN é persistente: qualquer operação matemática que envolva um NaN retornará NaN. Atenção: Ele é o único valor no JavaScript que não é igual a si mesmo. Portanto, para verificar se um dado é NaN, deve-se usar a função global isNaN() em vez dos operadores de igualdade tradicionais.

Comando para saber o tipo primitivo

O comando para saber o tipo primitivo é o (typeof) Exemplo: var n = 200 typeof n 'number' n = "Google" typeof n 'string' typeof 6 'number' typeof 6.5 'number' typeof "6.5" 'string' typeof [] 'Object' typeof {} 'Object' typeof function(){} 'function' typeof Undefined 'Undefined' typeof NaN 'number' typeof Infinity 'number' typeof null 'Object' // para o JS o null é um objeto

O sinal de igual (=) le-se "RECEBE"
É possível que o valor da variável fique sem nennhum valor dentro, inserindo o valor "null" na variável.
Na memória do computador é possível criar os espaços de variáveis dentro do computador, chamamos de "VAR".
Pode ser criado alguns tipos de variáveis (var) como números e caracteres.
Por exemplo:
Recebe números
var n1 = 5
var n2 = 8
var n3 = 10

Recebe caracteres
var s1 = 'JavaScript'
var s2 = 'Curso'
var s3 = 'Curso de JavaScript'
