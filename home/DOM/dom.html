Exercícios

Questão 01: O que significa a sigla DOM? Resposta: DOM significa Document Object Model, que é um modelo de objetos para documentos que permite o acesso e a manipulação dos componentes internos de um website usando JavaScript. Questão 02: Sabe montar a árvore DOM de um site? (Ex: window > document > html > head e body > h1, p, div, etc) Resposta: Sim, a árvore DOM é uma estrutura hierárquica que representa os elementos de um documento HTML. Ela começa com o objeto window, que contém o document. O document é o objeto raiz que representa a página web e contém os elementos html, head e body. O body, por sua vez, contém os elementos visíveis do site, como h1, p e div, além de tags aninhadas como strong dentro de um parágrafo. Questão 03: O que são os elementos Parent e os elementos Child no contexto do DOM? Resposta: Os elementos Parent são os elementos que contêm outros elementos, enquanto os elementos Child são os elementos que estão dentro de outros elementos. Por exemplo, no DOM, o body é o elemento parent de um parágrafo (p), e o parágrafo é o elemento child do body. Questão 04: Quais são os cinco principais métodos de seleção de elementos DOM dentro do JavaScript, e explique cada uma delas? Resposta: Os cinco principais métodos de seleção de elementos DOM dentro do JavaScript são: 1. getElementById() 2. getElementsByClassName() 3. getElementsByName() 4. getElementsByTagName() 5. querySelector() e querySelectorAll() Questão 05: Quais são os principais objetos que compõem a árvore DOM? Resposta: Os principais objetos que compõem a árvore DOM são: 1. window 2. document 3. html 4. head 5. body 6. h1, p, div, etc. Questão 06: Qual é a função do objeto window no DOM? Resposta: O objeto window é o objeto raiz do DOM e representa a janela do navegador. Ele contém outros objetos como location, document e history, além de métodos e propriedades para manipular a janela do navegador.
