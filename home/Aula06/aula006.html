Conversão números

Number.parseInt // Converte para números inteiros
Number.parseFloat // converte para números com pontos flutuante
Number // o JavaScript já entende o número digitado e já converte de acordo com a digitação.
Para converter para string pode ser feito de duas maneira, usando "String(n)" ou "n.toString()"

Formatando Strings

Exemplo 01:

var s = 'JavaScript'

Ao dar o comando 'Eu estou estudando s' para mostrar na tela não faz interpolação.
Vai mostrar 'Eu estou estudando s'

Para concatenar a variável guardada use o "+" para faze a concatenação: 'Eu estou estudando ' + s
Vai mostrar 'Eu estou estudando JavaScript'

Exemplo 02:

Usa template string ${variável} e tem que usar a craze (`)
`Eu estou estudando ${s}`

Por exemplo:

nome = 'Jailton'
idade = 45
nota = 9.5

Usando a concatenação: 'O aluno' + nome + 'com' + idade + 'anos tirou a nota' + nota
Apresentará na tela: O aluno Jailton com 45 anos tirou a nota 9.5

Usando template string: `O aluno ${nome} com ${idade} anos tirou a nota ${nota}`
Apresentará: O aluno Jailton com 45 anos tirou a nota 9.5

Transformar e contar Strings

Existem outras informações sobre string.

Vamos declarar a variável (var nome = Jailton)

Por exemplo o ".length" que contará a quantidade de caracteres sendo um atributo.

Exemplo:
var nome = window.prompt('Qual é o seu nome: ') //faz a pergunta na tela
document.write(`Seu nome tem ${nome.length} letras.`) // conta quantos caracteres a string tem

Outro exemplo é o ".toUpperCase()" que transforma tudo para MAIÚSCULAS.

Exemplo:
var nome = window.prompt('Qual é o seu nome: ') //faz a pergunta na tela
document.write(`E seu nome em letras maiúsculas é ${nome.toUpperCase()}.`) // transforma tudo em maiúsculas.

Outro exemplo é o "toLowerCase()" que transforma tudo para minúsculas.

Exemplo:
var nome = window.prompt('Qual é o seu nome: ') //faz a pergunta na tela
document.write(`E seu nome em letras minúsculas é ${nome.toLowerCase()}.`) // transforma tudo em minúsculas.

Formatando Números

Exemplo:
var n1 = 1545.5
n1
'1545.5' // mostra a variável

comando "toFixed"
n1.toFixed(2) // mostra o número com duas casas decimais
'1545.50'

comando .replace // transforma algo na ante e depois
n1.toFixed(2).replace('.' , ',') transforma o "ponto" para "vírgula"
mostra na tela: '1545,50'

//------- Observação: Você precisa converter o valor para número usando Number(): //--------- comando para transformar em moeda (Real Brasil)
n1.toLocaleString('pt-BR', {style: 'currency', currency: 'BRL'})
mostra na tela: 'R$ 1,545.50'

comando para transformar em moeda (Dolar)
n1.toLocaleString('pt-BR', {style: 'currency', currency: 'USD'})
mostra na tela: 'US$ 1,545.50'

comando para transformar em moeda (Euro)
n1.toLocaleString('pt-BR', {style: 'currency', currency: 'EUR'})
mostra na tela: '€ 1,545.50'
