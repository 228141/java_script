O que é JavaScript?

JavaScript, frequentemente abreviado como JS, é uma linguagem de programação que é uma das tecnologias centrais da World Wide Web, juntamente com HTML e CSS. Ela nos permite adicionar interatividade às páginas; por exemplo, você já deve ter visto sliders, alertas, interações de clique, pop-ups etc. em diferentes sites — tudo isso é construído usando JavaScript. Além de ser usado no navegador, também é usado em outros ambientes que não são navegadores, como Node.js para escrever código JavaScript do lado do servidor, Electron para escrever aplicativos de desktop, React Native para aplicativos móveis e assim por diante. O JS é uma linguagem leve, interpretada, dinâmica, suporta estilos de orientação a objetos, imperativos e declarativos. Observação IMPORTANTE: "Não confunda JavaScript com Java, pois possuí sintaxe e semânticas diferentes."

Importante: DevTool

DevTools (Ferramentas de Desenvolvedor) são um conjunto de ferramentas nativas integradas aos navegadores web (como Google Chrome, Firefox, Safari e Edge). Elas permitem inspecionar, depurar e modificar o código de sites e aplicações em tempo real, além de testar o desempenho e a responsividade. Para abrir o DevTools no seu navegador, você pode usar os seguintes atalhos ou métodos: Pressionar a tecla F12 Clicar com o botão direito em qualquer lugar da página e selecionar "Inspecionar" Usar o atalho Ctrl + Shift + I (no Windows/Linux) ou Cmd + Option + I (no Mac) O DevTools é dividido em várias abas e painéis. Os principais recursos que você encontrará são: 1. Elements (Elementos)Permite visualizar e alterar o código HTML e CSS de uma página. Você pode usar essa ferramenta para testar cores, fontes, tamanhos ou apagar elementos da tela. As alterações são refletidas na hora, mas desaparecem quando você atualiza a página. 2. Console (Console)Geralmente usado por desenvolvedores para exibir mensagens de erro, avisos ou informações sobre o sistema. Ele também permite executar comandos em JavaScript diretamente na página aberta. 3. Network (Rede)Exibe todos os arquivos que estão sendo carregados pelo site (imagens, scripts, folhas de estilo, etc.). É ideal para monitorar a velocidade de carregamento, verificar se há falhas no carregamento de dados ou analisar requisições a servidores. 4. Application (Aplicativo)Permite verificar o armazenamento local do navegador, dados em cache, cookies e bancos de dados do lado do cliente. 5. Device Mode (Modo Dispositivo)Geralmente acessado pelo ícone de celular/tablet, permite simular como o site se comporta em diferentes tamanhos de tela e resoluções móveis.Se você quer aprender como navegar por essas funcionalidades e utilizar o DevTools na prática:
